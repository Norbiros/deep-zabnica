# 🐟 Deep Żabnica

**Deep Żabnica** is a DIY underwater remotely operated submarine (ROV), named after one of the ocean’s strangest and 
most charming predators - [the frogfish (żabnica in Polish)](https://en.wikipedia.org/wiki/Lophius_piscatorius).

## 🚀 Project Goals

The project is part of HackClub's [Fallout](https://fallout.hackclub.com) initiative,
which encourages students to start their journey with hardware, so my goal is to **learn** and **have fun**!
